# Benjamin Zhang — Personal Website

Personal portfolio site built with React, TypeScript, Tailwind CSS, and Vite. Deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run lint` — lint with oxlint
- `npm run format` — format with Prettier

## Structure

```
src/components/   one component per page section
src/content/      all site text (edit here to change copy)
src/styles/       design tokens
public/           images, favicon, share image
docs/             PRD, plan, copy deck
```
